# de-notes

Learning notes for my 12-week move into data engineering (started Sep 29, 2026).

The hands-on project lives in [de-project-1](https://github.com/s80programmeomega/de-project-1). This repo holds the thinking behind it: weekly summaries, checkpoint answers, and a daily journal.

## Contents
- `tracker.md` — the 12-week checklist (tick boxes as I finish each day)
- `journal.md` — one line per day: what I learned or what confused me
- `week-NN/` — one folder per week, created when the week starts
  - `summary.md` — checkpoint answers and what is still unclear
  - other notes for that week (data dictionary, cheat sheets, comparisons)

## Plan at a glance
- **Phase 1 (Weeks 1–4):** SQL, query performance, dimensional modeling
- **Phase 2 (Weeks 5–8):** ingestion, Airflow, dbt, data quality and CI
- **Phase 3 (Weeks 9–12):** AWS (S3, Glue, Athena), Redshift and Spark basics, capstone
